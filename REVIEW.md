## Items reviewed and not yet classified as defects

- `IST` defines the UTC+05:30 timezone offset. This is appropriate for representing Indian Standard Time, but individual date/time conversions still need to follow the assignment's rules.
- `MongoClient` and the database selection use environment variables with local defaults. This is useful for configuration; the actual deployment configuration must be verified separately.
- The starter uses FastAPI endpoints and Pydantic request models. These are appropriate choices for this application, although the models may not enforce every requirement in the API contract.

Additional defects will be added as they are verified and fixed.
